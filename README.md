# busauto-merchant-feed

Публічний файл-фід товарів BusAuto для Google Merchant Center (scheduled fetch).

Генерується автоматично з приватного репозиторію `busauto-tools`
(`generate_merchant_feed.py`). Не редагувати вручну — файли
перезаписуються при кожному запуску.

Дані тут — те саме, що вже публічно показується на busauto.ua кожному
відвідувачу (ціна, наявність, назва товару) — нічого конфіденційного.

Файли:
- `feeds/merchant_feed_uk.tsv` — українська версія
- `feeds/merchant_feed_ru.tsv` — російська версія
